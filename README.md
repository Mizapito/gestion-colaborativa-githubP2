##  Actividad a Realizar

###  Objetivo
Aplicar un flujo de trabajo colaborativo utilizando Git y GitHub para gestionar correctamente cambios, responsabilidades, revision de codigo e integracion de funcionalidades.

###  Enunciado
Continuar el desarrollo de un sitio web utilizando un unico repositorio en GitHub. Cada integrante debera desarrollar una funcionalidad diferente siguiendo obligatoriamente el siguiente flujo de trabajo:

Issue -> Branch -> Commits -> Push -> Pull Request -> Code Review -> Merge -> Cierre del Issue

---

###  Requisitos por Integrante

Cada miembro del equipo debe cumplir con los siguientes pasos:

1. Crear un Issue con una descripcion clara y criterios de aceptacion definidos.
2. Crear una rama especifica (branch) para desarrollar la funcionalidad asignada.
3. Realizar minimo 2 commits claros y significativos.
4. Publicar la rama en el repositorio remoto de GitHub (git push).
5. Crear un Pull Request (PR) apuntando hacia la rama main.
6. Vincular el PR con el Issue correspondiente utilizando la palabra clave Closes #N en la descripcion.
7. Revisar el Pull Request de otro integrante del equipo.
8. Registrar al menos un comentario de Code Review.
9. Aplicar correcciones solicitadas durante la revision, cuando corresponda.
10. Realizar el Merge unicamente despues de la revision y aprobacion del Pull Request.
11. Mantener actualizada la rama main en su entorno local.

---

###  Reglas de Trabajo

* Prohibido trabajar directamente sobre main.
* Cada funcionalidad debe contar con su propio Issue y Branch.
* Los mensajes de commit deben describir de forma clara y concisa el cambio realizado.
* Todo Pull Request debe ser revisado y aprobado por otro compañero antes de integrarse.
* Las ramas de trabajo deberan eliminarse despues de completar el merge.
* El repositorio final debe contener todas las funcionalidades correctamente integradas y funcionando en main.
